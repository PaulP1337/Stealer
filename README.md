# Stealer
Всех приветствую, это написанный мной на языке python локальный стиллер.
Написан по аналогии с инструментом mimikatz.
Скрипт раскидывает полученные данные по 2 папкам, которые он создаст при первом запуске.
В репозитории лежат 2 файла, pp4grab S и pp4grab SH, первый это small версия, он ищет только .txt файлы, второй это shtandart, он ищет куки тг, папки тг и .txt файлы.
Не запускайте в корне диска, иначе метод os.walk полностью его пропустит не просканировав, всегда держите этот скрипт в буферной папке.

**Автор не призывает к распространению и использованию вредоносного ПО, данный софт написан исключительно в образовательных целях.**
