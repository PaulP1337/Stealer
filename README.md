# Stealer
Всех приветствую, это написанный мной на языке python локальный стиллер.
Написан по аналогии с инструментом mimikatz.
Скрипт раскидывает полученные данные по 3 папкам, которые он создаст при первом запуске.
В репозитории лежат 2 файла, pp4grab S и pp4grab H, первый это small версия, он ищет только .txt файлы, второй это heavy, он ищет все, папки, куки, и в том числе .txt файлы.

**Автор не призывает к распространению и использованию вредоносного ПО, данный софт написан исключительно в образовательных целях.**
